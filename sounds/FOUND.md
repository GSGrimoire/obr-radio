# Sounds found, used and not yet used

A log of where the radio's sounds come from, kept so anything can be credited and
anything worth using later can be found again. Searched 2026-10-01.

**Licences.** "CC0" and "CC BY" here are what Freesound's licence filter returned
for the search. A file is only used after `tools/sounds.py` has read the licence on
the sound's own page; the record of that, with what was changed, is
`tools/dnm-sources.lock.json`, and the credits page shows it. CC BY means the
author must be credited and changes noted, which the credits page does.

**Already in a pack** are marked with the name they have there.
